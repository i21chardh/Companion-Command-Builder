# Security

Please do not include passwords, API keys, Companion secrets, private network inventories, or production configuration exports in a public issue.

For a suspected vulnerability, open a GitHub issue containing only non-sensitive reproduction details and request a private follow-up channel. Rotate any credential that may have been exposed.

Companion Command Builder is intended to run on a trusted production network. Do not expose its local HTTP service or the Companion configuration interface directly to the public internet.
